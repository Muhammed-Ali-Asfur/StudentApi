# Student API

A secure RESTful Web API developed with ASP.NET Core for managing student data with authentication and authorization features.

## Features

- Student CRUD operations
- JWT Authentication
- Role-based authorization
- Policy-based authorization
- Owner-based access control
- Secure API endpoints
- Swagger API documentation

## Technologies

- C#
- ASP.NET Core Web API
- JWT Authentication
- Authorization Policies
- REST API
- Swagger
- Dependency Injection
- LINQ
